What is a Program?

Think of it as giving instructions!

A program is a set of instructions for a computer
We write instructions using a programming language (like Python)
The "grammar" of this language is called syntax
We save these instructions in a script file (e.g., hello.py)

🍳 Like a Recipe!

Just like a cooking recipe tells you step-by-step how to make food, a program tells the computer step-by-step what to do.

10 / 98

⚡ How Code Becomes Action

Ever wonder what happens when you hit "Run"?

1
You write: print("Hello, World!") in your .py file
2
Python Interpreter: A special program that reads and understands your Python code line by line
3
Translation: The interpreter converts your code into instructions the computer can understand
4
Execution: The computer displays "Hello, World!" on your screen!

It's not magic—it's the Python interpreter working behind the scenes!

✨ Your First Python Script

Create hello.py and type:

# This is my first Python program print("Hello, World!")
Comments: Lines starting with # are ignored by Python (notes for humans!)
Strings: Text wrapped in quotes ("Hello, World!") is called a string
1
Save and run (▶️ button or F5)
2
Observe output: Hello, World!
