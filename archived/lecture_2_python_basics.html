📐 Python Indentation

Indentation = spaces at the beginning of a code line

In Python, indentation indicates a block of code (unlike { } in other languages)

✅ Correct Indentation

if 5 > 2: print("Five is greater than two!") print("This is inside the if block") for i in range(3): print(f"Number: {i}") if i > 1: print("Greater than 1")

❌ Wrong Indentation

if 5 > 2: print("This will cause an error!") # IndentationError: expected an indented block for i in range(3): print(f"Number: {i}") print("Wrong indentation level") # IndentationError: unindent does not match

Best Practice: Use 4 spaces for each indentation level (PEP 8 standard)

📜 Python Coding Style (PEP 8)

PEP 8 is the official Python style guide

Read more: peps.python.org/pep-0008/

📏 Line Length

Maximum: 79 characters per line

Docstrings: 72 characters

🔤 Naming Conventions

Variables: snake_case

Functions: snake_case

Classes: PascalCase

Constants: UPPER_CASE

📐 Indentation

Use: 4 spaces per level

Avoid: Tabs

Never: Mix tabs and spaces

🚀 Blank Lines

Top-level functions: 2 blank lines

Class methods: 1 blank line

Logical sections: 1 blank line

# ✅ Good PEP 8 Style def calculate_area(length, width): """Calculate the area of a rectangle.""" return length * width class Rectangle: """A simple rectangle class.""" def __init__(self, length, width): self.length = length self.width = width def get_area(self): """Return the area of the rectangle.""" return self.length * self.width # Constants PI = 3.14159 MAX_USERS = 1000

🔍 Accessing Values in Strings

String Indexing

var1 = "MANU!" var2 = "Software Testing" # Positive indexing (from start) print("var1[0]:", var1[0]) # M print("var1[1]:", var1[1]) # A print("var1[4]:", var1[4]) # ! # Negative indexing (from end) print("var1[-1]:", var1[-1]) # ! print("var1[-2]:", var1[-2]) # U # Index visualization for "MANU!" # M A N U ! # 0 1 2 3 4 (positive) #-5 -4 -3 -2 -1 (negative)

🔗 String join() Method

Basic Join

# Join characters with a separator print(":".join("Python")) # Output: P:y:t:h:o:n # Join list elements words = ["Hello", "World", "Python"] sentence = " ".join(words) print(sentence) # Hello World Python # Different separators print("-".join(words)) # Hello-World-Python print("***".join(words)) # Hello***World***Python

Join with Numbers

# Numbers need to be converted to strings numbers = [1, 2, 3, 4, 5] # This will cause an error: # result = ",".join(numbers) # TypeError! # Correct way: result = ",".join(str(num) for num in numbers) print(result) # 1,2,3,4,5 # Or convert list first str_numbers = [str(num) for num in numbers] result2 = ",".join(str_numbers) print(result2) # 1,2,3,4,5

Practical Examples

# Create CSV data headers = ["Name", "Age", "City"] csv_header = ",".join(headers) print(csv_header) # Name,Age,City data = ["Isaac", "25", "Nairobi"] csv_row = ",".join(data) print(csv_row) # Isaac,25,Nairobi # File path creation path_parts = ["home", "user", "documents", "file.txt"] file_path = "/".join(path_parts) print(file_path) # home/user/documents/file.txt

Advanced Usage

# Join with conditional filtering words = ["apple", "", "banana", "", "cherry"] # Remove empty strings clean_sentence = " ".join(word for word in words if word) print(clean_sentence) # apple banana cherry # Join with formatting prices = [19.99, 25.50, 12.75] price_list = ", ".join(f"${price:.2f}" for price in prices) print(price_list) # $19.99, $25.50, $12.75 # Create HTML tags = ["python", "programming", "tutorial"] html_tags = " ".join(f"#{tag}" for tag in tags) print(html_tags) # #python #programming #tutorial

Remember: join() is called on the separator string, not the list!

🔄 Reversing Strings

Method 1: Using reversed()

string = "12345" reversed_string = ''.join(reversed(string)) print(reversed_string) # 54321 # How it works: # 1. reversed(string) creates an iterator # 2. join() combines the characters back into a string # With words word = "Python" backward = ''.join(reversed(word)) print(backward) # nohtyP

Method 2: Slicing

string = "12345" reversed_string = string[::-1] print(reversed_string) # 54321 # More examples text = "Hello World" print(text[::-1]) # dlroW olleH name = "Isaac" print(name[::-1]) # caasI # Partial reversal print(text[6::-1]) # olleH (reverse first 7 chars)

Method 3: Loop (Manual)

string = "12345" reversed_string = "" # Build reversed string character by character for char in string: reversed_string = char + reversed_string print(reversed_string) # 54321 # Alternative loop method string = "Python" reversed_string = "" for i in range(len(string) - 1, -1, -1): reversed_string += string[i] print(reversed_string) # nohtyP

Practical Applications

# Check if string is a palindrome def is_palindrome(text): clean_text = text.lower().replace(" ", "") return clean_text == clean_text[::-1] print(is_palindrome("racecar")) # True print(is_palindrome("A man a plan a canal Panama")) # False print(is_palindrome("Madam")) # True # Reverse words in a sentence sentence = "Hello World Python" words = sentence.split() reversed_words = [word[::-1] for word in words] result = " ".join(reversed_words) print(result) # olleH dlroW nohtyP

Performance: Slicing ([::-1]) is usually the fastest method for simple string reversal!

✂️ Splitting Strings

Basic split()

# Split by whitespace (default) word = "guru99 career guru99" result = word.split() print(result) # ['guru99', 'career', 'guru99'] # Split by specific character sentence = "apple,banana,cherry" fruits = sentence.split(',') print(fruits) # ['apple', 'banana', 'cherry'] # Split by space explicitly text = "Hello World Python" words = text.split(' ') print(words) # ['Hello', 'World', 'Python']

Split with Different Delimiters

word = "guru99 career guru99" # Split by 'r' result = word.split('r') print(result) # ['gu', 'u99 ca', 'ee', ' gu', 'u99'] # Split by longer strings email = "user@example.com" parts = email.split('@') print(parts) # ['user', 'example.com'] # Split file path path = "home/user/documents/file.txt" directories = path.split('/') print(directories) # ['home', 'user', 'documents', 'file.txt']

Limiting Splits

# Limit number of splits text = "apple-banana-cherry-date" result = text.split('-', 2) # Split only twice print(result) # ['apple', 'banana', 'cherry-date'] # Split from the right text = "file.backup.txt" result = text.rsplit('.', 1) # Split once from right print(result) # ['file.backup', 'txt'] # Get file name and extension filename, extension = text.rsplit('.', 1) print(f"Name: {filename}, Ext: {extension}")

Real-world Examples

# Parse CSV data csv_line = "Isaac,25,Nairobi,Engineer" data = csv_line.split(',') name, age, city, job = data print(f"Name: {name}, Age: {age}") # Process log entries log_entry = "2024-01-15 10:30:45 ERROR Connection failed" parts = log_entry.split(' ', 3) date, time, level, message = parts print(f"Level: {level}, Message: {message}") # Split lines in text text = """Line 1 Line 2 Line 3""" lines = text.split('\n') print(lines) # ['Line 1', 'Line 2', 'Line 3']

Pro Tip: Use strip() with split() to handle extra whitespace: [item.strip() for item in text.split(',')]
